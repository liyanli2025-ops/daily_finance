# 财经播客修复流程与验收

## 目标与约束

面向用户A股、港股日内至数日的决策，兼顾影响A/H的海外变化。自选股以App实时列表为准。早6点与收盘后16—18点，内容有多少讲多少，整期不超过20分钟。

信息、行情技术、主观研判共同构成分析。事实准确、观点有方向、反证充分、预测期限与失效条件可检查；不要求预测有事实般确定性。听感要自然、重点鲜明，不能新闻流水账或指标报数。

当期资料用于当期检索与生成，采用短期工作集、到期清理。外部资料库按需检索，不整库镜像，不要求用户注册IMA来完成当前修复。公开接口有文档不等于具体共享库有权限。保留成品及必要引用，不将临时原文无限积累。

不以文章数、来源名数、审查分数或离线测试数证明信息完整或预测准确。公开采集不调用模型；生成按既有调用预算执行，不自动反复付费测试。不改其他项目、用户密钥和App主数据库。

## 技术方法的接入顺序

第一层以可重复计算的价格结构、趋势/动量、波动、量价和相对强弱组成研究材料，不把均线、MACD等相关指标当独立证据投票。结合市场状态比较趋势延续和均值回归两种解释。

第二层需要分钟数据及充分市场样本，补多周期与盘中分析。周线按市场周收盘规则形成，不把本周未完成周线冒充完整周线；市场宽度需明确股票全集与停牌/缺失处理。

缠论、威科夫、波浪等按明确识别口径逐个评估。图形解读可主观，但不能让模型凭空识别结构；需后续K线确认的分型、笔、转折必须记录确认日，不能回填历史信号。暂不承诺所有流派同时接入，也不以流派名称替代验证。

## 统一验收顺序

1. 离线回归：工作集生命周期、检索引用、工具边界、无未来数据、指标与结构计算、失败和预算。
2. 公开数据验收：整池质量、未读缺口、当前App自选股及全市场覆盖、时间口径。无模型/音频费用。
3. 合并包安装验证：已确认版本兼容、私有备份、主数据库与其他项目保留、财经服务健康。
4. 只在资料及工具合格后安排少量真实生成，保留初稿/审查/最终稿及账单用量，不因中断盲目重跑。
5. 最终音频与连续数期复盘。不能凭单期审查通过宣布专业性和预测效果达标。

本文件是阶段流程，不代表全部阶段已完成。本轮开发与后续进度以真实改动及验证记录更新。
