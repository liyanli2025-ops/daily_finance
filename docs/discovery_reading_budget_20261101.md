# 通用取材：补读分配、候选复用与调用前检查（2026-11-01，未部署）

本轮继续修改自动取材器，没有补某一期新闻、添加固定股票或针对新站点修模板。基于上一轮逐轮反馈机制，修正可能导致漏读、重复检索和过早拒绝的通用行为。

## 补读按取材顺序轮流分配，并先检查尾段

此前 `complete_local_reads` 按证据 ID 排序，一次补完一篇再处理下一篇；ID 是 hash，不能代表重要性。在有限额度下，一篇长稿可能先吃掉全部额度，其他稿后段一直未提供。

现在按实际成功阅读回执的顺序排队，对同一轮尚未分配的文章分享剩余额度；每篇每次最多4,000字符，仍受原整期额度、实际输入空间和截止约束。在自动取材循环内，还按剩余决策轮次预留后续补读额度，避免首批一篇长稿先用完整期额度；模型可通过显式 `read_more` 给重要稿件优先使用剩余额度。存在未提供的结尾时先读尾段，再填中间缺口。若额度不足，原文保留、未提供区间仍明确列出，不把尾段抽读冒充全文阅读。显式 `read_more` 和自动补读继续共用字符额度。

这个策略不判断文章价值，也不保证结尾一定有反证；模型仍负责选择值得读的稿件。它改善的是已经选中稿件之间的补读分配，没有增加模型、搜索、URL或总时间上限。

## 搜索建议必须考虑后续能否阅读

此前只看搜索额度是否剩余；即使新增 URL 阅读额度已耗尽，反馈仍可能标“继续搜索”为可执行，执行器也会真发搜索请求，取得的新目录却读不了。

现在缺口反馈同时考虑搜索与 URL 额度，并区分新的候选和本期可复用正文。执行器在新增 URL 额度耗尽后拒绝新的搜索，返回 `no_body_budget_for_new_search`，不调用搜索适配器；已缓存的同查询目录可继续复用。此约束只针对主资料取材器，不改其他搜索用途。

已存正文可在没有新增 URL 额度时重新按另一个合法研究用途读取，不再请求网络；未存正文不能因“可复用”标签绕过额度。反馈标明 `reusable_candidate_ids / fresh_candidate_ids / blocked_by`，程序不因搜索额度尚有剩余就盲目消费。

## 主体不匹配与网页失败分开记录

此前任一 `read` 被拒绝，就可能在反馈里全局排除该候选；“不属于当前股票”被混同为“这个网页读不了”。

现在保留终止性读取失败、被拒绝的公司范围和已存正文 ID。页面失败、受限或不支持的类型继续排除，失败 URL 不重试；某家公司匹配失败仅阻止该公司方向再次尝试，合格缓存可以用于另一个研究方向，由模型选择。被拒绝的公司材料不会计入其直接资料，也不会因为留在缓存就自动进入报告。

对于标题只有“经营情况公告”这类候选：若确实来自当前公司 scope 的定向检索，允许在既有 URL 额度内读正文，再核对公司名称或独立股票代码；标题和摘要均无公司线索、也没有相应定向检索关联的，仍在请求前拒绝。数字代码增加左右数字边界，避免将更长数字中的子串当公司代码。这只是主体线索检查，`subject_verified` 仍为 false，不是发行人认证或独立事实核实。

## 搜索入口不可用时，先于模型调用停止

新增 `web_research.search_availability()`，只读当前进程的启用状态、是否配置账户及已有失败台账，不发送网络请求、不返回密钥或其hash。默认取材器在第一次模型决策前调用它；搜索关闭、缺账户或路径已被暂停时，以 `discovery_search_unavailable_before_model` 停止。不会先消耗模型请求再发现工具不可用。

显式注入的搜索适配器由调用方负责可用性，既有隔离 runner 的临时配置和固定失败 marker 不变，没有新建收费通道或重置试验。运行条件预检不是新授权或联网成功判定。

## 实际执行与验收边界

本轮只执行保存资料的真实本地阅读和免费入口状态读取。两组保存资料分别含3份、7份正文，没有合成网页，也没有模拟模型决策来冒充真实自动取材。

对10,743字符长文，首次提供前4,000字符；新版实际先提供 `[6743,10743)` 的4,000字符尾段，再提供 `[4000,6743)` 的2,743字符中间缺口。最终存储文本范围完整提供，正文 hash、原截止和观察时间均不更新。这里只证实本地工具提供的文字，不证明模型已阅读或事实正确。0新HTTP、0搜索、0收费模型、0TTS。

当前工作环境实际返回 `search_availability={available:false, reason:search_disabled}`，不代表另一台生产服务器的状态；没有修改此状态或恢复生产。无法据本轮声称新日期实网自动搜索/换源通过。
