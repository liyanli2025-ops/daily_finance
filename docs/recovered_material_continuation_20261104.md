## 本次改动

- 通用恢复模块只消费已有 HTTP 200 快照中的解析失败，校验 URL、字节数、SHA、原截止、检查点与正文片段。HTTP 失败、访问限制、冲突 JSON 键不在恢复范围内。原始结果、失败回执和停用台账保留。
- 同值重复键只记录规范化结果，不执行旧回复的工具或结束决定。新正文进入单独准备的状态，交给原取材控制器重新选择、补查及判断是否结束。
- 免费预览仅在内存恢复资料，不下载网页、不调用模型或搜索、不复制旧 episode。显式运行才复制一份本地工作目录，并继续原预算；已成功响应的真实正文区间才恢复为模型送达，不能把新恢复文本冒充已读。
- 新提供的文本扣原本地阅读预算，整份正文保留。未提供的 MUFG 后段仍须补读；正文恢复不增加 URL 次数，也不返还此前失败请求费用。
- 正文反馈、提示词和报告导入统一限制用途：晨报不能补齐收盘/结算；银行评论不能证明央行原始发布；同行材料不能补齐自选股直接资料。未被规则限制也不代表已验证交易时段或来源身份。
- 模型可以明确把同行资料用于行业背景；不自动将其算作行业覆盖，更不改成原公司主资料。
