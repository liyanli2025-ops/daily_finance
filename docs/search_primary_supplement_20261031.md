# 主动搜索为主，固定信源只补增量

用户最新定位优先于“固定源先铺底、主动搜索补漏”的旧描述。主动搜索形成当期主资料，固定源辅助发现遗漏、更新、原始依据、反证和重要细节。不是再并行下载一批相同的大新闻。

## 用户纠正：先收集信息和讨论本身，不是生成追问

上一版用财务追问表格解释采集需求，偏离用户要求。用户需要的是基础信息，以及正文细节或公开论坛中的据报事项、采访说法、爆料、投资者讨论、观察和猜测。这些先作为素材记录，分析在后，不要求每条素材先具备完整投资逻辑。

| 要收集的素材 | 需要保留的内容 |
|---|---|
| 基础信息 | 具体数字、口径、业务/产品/客户背景、日期和条款；保留来源和上下文 |
| 正文里的消息 | 采访对象具体说了什么、知情人士如何描述、报道中有没有小范围变化或新细节 |
| 爆料与据报事项 | 原始说法、出处、时间、匿名/公开身份、现有依据与当事方回应；未确认不删成“无消息” |
| 投资者观察和讨论 | 原帖/评论、具体论据、不同解释、猜测与争议；不只抓热榜标题，也不把刷屏当多份证实 |
| 后续与反方 | 新回复、澄清、撤回、更正和不同论据；同主题不等于重复信息 |

记录的是“谁在何时说了什么，以及目前能核到什么”。原话与转述、事实与个人观察/猜测/情绪分别标明。不要替匿名账号编造行业身份；只有搜索片段、原帖未读或时间未知时如实记录。没有完整因果链不作为提前拒收具体投资线索的理由；重要性、可信度、分析结论和节目采用在后续判断。

与投资无关的闲聊、广告和没有新增内容的喊涨喊跌不堆进资料。仅公开可访问内容，不绕过登录/付费或私人权限。讨论量、点赞和转载数不自动代表真实性、全网热度或市场未定价。

此次修改的是正式提示词与需求口径；没有新增/验证论坛采集器，不声称已抓到任何论坛帖子。后续需要以真实原帖、回复上下文、时间与来源字段检验入口，不能继续只证明新闻列表可抓就称满足本项。

## 增量标准与费用

“已覆盖”具体到主体、事件、期间、指标/条款、版本、上游来源与实际提供的正文范围，而不是同主题或同标题。
固定源追加采集应说明属于遗漏、更新、基础信息/上下文、具体说法/讨论、反方或待核线索。未核实不等于无价值，也不要求采集时已经形成交易判断；普通无关财报、纯转述和重复评论不因来源不同再占位。

先用本期资料池；需要发现新问题时轻量扫描目录/版本信息，不把固定源局限在搜索已选主题。元信息重复可帮助识别重复；没有必要把全部重复正文再下载一遍。未知增量不假称无增量，新时点/回应/原始披露不得被相似标题误删。

研究与口播不固定新增模型阶段；沿用关闭自动重试和整篇修稿。提示词增加输入量，不承诺一定降低总账单。

## 本次实际落实

1. 正式`research_desk.INSTRUCTIONS`写入上述主辅关系、增量理由、弱信号与反证要求，经共同`initial_prompt`进入分析及成本预检。
2. `read_public_url`跨采集渠道复用当期已接纳、窗口内且有正文范围标记的同URL文字，而非仅复用自己的URL缓存；过滤追踪参数后匹配。RSS/未知摘要不替代正文，不凭同标题跳过另一篇材料。
3. 复用结果明确HTTP请求为零、未检查远端版本，不冒充最新网络核验。复用保留原证据ID和字符范围。修订、滚动页和后续版本仍需另核；这是当前截面复用，不是完整版本监测。
4. 43项网页/研究协议/取材回归通过，新增用例验证固定正文复用、摘要仍需取原文、同标题的不同URL反方仍可读取。全部模拟，无实际媒体、LLM或付费搜索请求。

## 尚未实现，不能对用户宣称已完成

更新：已新增`collect_all(primary_news=...)`分支和`collect_discussions`按需参与者工具，详见[实际源接入](participant_sources_20261031.md)。提供主资料的新分支不再运行原媒体/RSS扫库；默认未提供主资料的旧调用方仍走兼容路径。尚未改成全自动的“主动搜索先行→固定源仅按增量任务读取”，也没有实现跨站语义事实判重或让所有固定采集器调用前都跳过已覆盖事件。不能拿同URL复用宣称整个采集流程已避免重复。

通用搜索适配器仍默认关闭，尚无服务器真实验收；当前聊天搜索不等于Ofox/服务器自动搜索。后续需要先落实可用且费用明确的搜索能力，再让主资料/覆盖账本驱动补充任务。不可静默恢复全源扫描并当作主动搜索成功，也不可未经授权启用付费搜索。

新编排应保留既有固定源解析与失败暂停，先做本地/缓存回放，检查同题更新、反证和原始材料不被误删，再做一次新一期联合验收。不得重复付费运行旧试验。服务器未部署，自动化继续暂停。
