# 公开讨论：减少入口与发言者集中，保留可核查线索

2026-10-31。本轮为上一轮参与者采集的扩展，源码未部署服务器；不调用付费模型，不恢复调度。

## 针对的问题

少量详情页不代表论坛全貌。旧实现把整页主帖及回复拼接后，只初读前部片段。即使抓到了后部较具体的发言，也可能没有提供给模型。另一方面，某个活跃账号、同一长帖或同一目录很容易占据读取机会。仅增加帖子数不能证明质量改善。

## 本次实现

1. 新增集思录债券/可转债、套利两个目录。各做一次匿名公共HTTP，均返回可解析目录；没有重测旧失败入口。解析仅取真实讨论列表，排除付费置顶广告和话题导航。目录里的最后回复时间是活动线索，不作为原帖发布时间或事件发生时间。
2. 目录发现与首次正文机会交替进行，避免新增目录和动态自选股目录先耗尽全部25秒时间预算。剩余候选继续按来源轮转；未检查目录/未读候选显式保存，无固定每日篇数指标。
3. 同链接的多目录发现合并。已有正文按URL复用；目录确有更新日期线索时，可更新成功页缓存。不同缓存版本仍检查原URL失败台账，结构错误或HTTP失败不借新版本重试。未见更新线索不代表远端没变。
4. 新主资料补充分支和按需工具默认使用`granularity=statements`。每条窗口内可见发言生成独立、内容不可变的证据ID，保留账号、时间、原链接、发言位置、引用上下文。旧主帖背景只附有范围标识的片段，未来日期不混入背景。完整可见整页可通过同链接与`granularity=thread`补读。
5. 初读按来源、帖子和公开账号轮转。文本中的具体经营/交易词、来源链接、比较和反方表述只用于安排阅读，不是投资价值、真实性、独立性或作者资历评分。数字本身不自动获得优先级。其余发言仍在本期池中可检索/补读，不因为暂未初读而丢弃。
6. 工具返回完整发言标题目录，正文初包仍按实际范围提供；不重复把所有正文发给模型，不新增LLM阶段。全池和诊断仍遵循原有当期生命周期。一次工具包大小不是每日资料数量上限。
7. 增加来源使用回执：每期独立文件，记录入池、准备、已确认提供范围和报告引用数，避免并发覆盖公共计数器；只留无正文元数据近7天。`app.discussion_check --contributions`仅查看这些记录，无网络或模型请求。**引用/使用不是价值认证**；目前尚无多期人工价值评级，不据抓取/引用量自动给来源升降频。

## 保存样本的离线结果

- 原4个目录的不同帖子链接114个。新2个目录共55个不同链接，53个未出现在此前目录样本中。新候选未读取详情，不能说新增53条有效消息。
- 仍是此前5个详情页、64条可见主帖/回复，53个不同公开显示名；显示名不是53位已核实的人。
- 64条发言分别可读，初包6000字符实际提供14条的全部或部分文本；不是14篇新新闻，也不是新的数量上限。
- 旧长帖后部那条融资余额与流通市值比较的发言位于新读取次序第9，实际进入初包。它仍是未经核实的个人数据分析；比例变化不能证明没有主动去杠杆。
- 样本含债市/信用猜测、杠杆讨论、短线复盘、美股技术观点和个股预期，价值依旧不均匀。不把五个方便取得的样本当作来源稳定有效率估计。

## 仍需完成的事情

行业从业者、独立研究者等身份没有核实；不能把公开账号包装成专家或游资。新目录的53个额外链接不证明这些群体已经覆盖。需要后续有效的新页样本，以及多期“补了什么事实、提供了什么可核查线索/反方、纠正了什么判断”的复核，再决定哪些源值得增加监测。

主动搜索自动调度仍未完整接入；旧调用方不传`primary_news`仍走兼容路径。此次不改调度、不自动运行采集或收费验收。下一次真实模型验证前须先免费检查新资料、实际输入范围与请求长度；已有付费试验不删除标记重跑。

## 验证

完整717项离线回归通过。新增两次公开目录HTTP以外，保存样本回放和测试没有访问采集源；收费模型、TTS调用均为0。
