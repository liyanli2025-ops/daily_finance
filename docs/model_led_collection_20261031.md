# 从接口测试回到完整研究任务

## 本轮诊断

服务器首次Tavily试验返回搜索目录，但四个正文样本全部失败。美股查询混入台湾收评，牧原查询返回山东药玻，港股首条读取了指数介绍页。密钥/搜索连接已能返回结果，资料质量与正文读取尚未通过。不得删除 `tavily-acceptance-v1.started` 再跑同一收费试验。

原有完整研究要求仍在 `research_desk.INSTRUCTIONS`。此前用户认可的聊天辅助样本及逐项阅读范围保存在本地 `outputs/20261031模型主动搜索采集样本.html` 和 `render_search_sample_20261031.py`：包括A/H分化、美股收盘与重要公司、政策、国际能源、动态自选股，以及原披露/媒体转述的区分。样本靠聊天中主动搜索与人工阅读组织，不能据此宣称服务器复现了同等能力。本轮不把这些旧材料重新冒充新采集。

## 已实现的代码

`primary_discovery.discover` 是报告生成之前的主资料研究循环。使用原有完整研究任务作为共享需求来源，另定义收集协议，不再发送四条写死的搜索词。模型通过结构化动作自主选择搜索、阅读候选、补读已存正文后部，再交资料底稿。`discover_current` 从App数据库读取名单并在结束时再次核对；无旧名单回退。

流程为：完整任务与实际日期/名单/资源上限 → 模型决定具体检索 → 搜索目录 → 模型判断候选相关性与重要性 → 选择正文/不同来源/继续检索 → 事件及取舍理由、范围缺口。目录不是正文；正文范围提供不等于模型已理解或事实已核实。

- 每条工具请求必须说明目的；同一URL保留不同发现路径，同一事件可有原披露、媒体和反证，不按同公司全删。语义事件合并仍依赖模型判断，不宣称代码已自动准确去重。
- 自选股direct读取要求候选及所提供文字含当前公司名/代码；同业和产业链用不同relation及关联说明。这是粗粒度词项保护，不能证明关联准确，不能识别只在推荐栏提及等全部边界。
- 拒绝已知首页/栏目/恒指介绍页形态作为新闻正文；不是完整网页类型分类器。美股/台湾等市场语义判断仍交模型，必须实测，不宣称规则已解决所有跑偏。
- 同查询、同检索模式复用；同URL包括失败结果不重新请求。正文失败后模型可挑其他结果。`read_more`读取已保存正文后部，不再下载网页。
- 每个研究范围及当前股票必须留下实际状态和说明。无正文不能用候选编号交事件；有缺口的结果为 `partial_materials_for_human_review`，没有正文为 `insufficient_body_evidence`。不把“跑完”当“够用”。

旧适配器默认topic=news，现保留旧调用兼容性，同时允许新循环显式选general/news，缓存按模式区分；仍固定basic且关闭auto_parameters，不静默升级advanced。官方说明news偏实时主流新闻，general覆盖较宽来源；这不是中文检索质量一定提升的证据。见[Tavily Search官方参数](https://docs.tavily.com/documentation/api-reference/endpoint/search)。尚未实测模式切换后的真实结果。

## 费用与运行边界

默认试验资源上限：6次模型决策入口、至多4次搜索工具调用、12个正文URL、48,000输入字符/请求、3,000输出token/请求、240秒。服从更低的搜索配置和现有网关约束。它们是停止保护，不是篇数目标，不承诺以该预算完成全市场研究；输入/时间/请求耗尽就保存未完成状态，不能静默截材料后假称完成。

没有创建新的生产自动任务；不修改.env、不临时解除模型维护暂停、不自动审查/修稿/TTS/发布。真实模型默认走现有网关与用量记录，配置非零模型重试时拒绝此入口。每次决策/工具前后保存私有检查点，素材沿用工作区24小时生命周期。

当前新增命令 `python -m app.primary_discovery_check`（部署之后才存在）仅零网络预检；`--show-prompt`打印完整实际任务，没有收费运行参数。现在不要要求用户直接执行未安装的模块。正式付费试验仍需独立、有防重复标记和明确预算的执行封装，不能直接让用户调用内部函数绕过维护暂停。

## 验收与接下来工作

离线场景验证了：选择第二条结果而非第一条、拒绝无关公司直接材料、拒绝恒指介绍页、失败链接换其他来源且不重试原链接、已存后部补读、请求包先校验再支出、搜索账户失败不重复探测、预算停止、摘要不得当正文、动态名单与完整范围回执、维护暂停不被覆盖。模型回复与搜索返回均是测试夹具；这不证明Claude实际判断正确，也没有重新测试失败站点。

下一步合并部署并进行一轮预算透明的新资料真实模型研究验收；先比较新闻/通用搜索、文章相关性、日期和正文可读性，再判断事件重要性、去重、跨市场覆盖与自选股关系。需要时针对保存的成功页面补适配器，不重试已暂停路径，不把全文获取困难用放松时间/付费墙/证据要求掩盖。

验收通过前不连接自动报告调度。通过后将实际取得的主资料交给现有 `collect_all(primary_news=...)` 做有理由的固定源/讨论/技术面增量，再接分析与口播。当前未完成该自动串联、实际选材质量或整期音频验收，不给虚假的总体完成百分比。
