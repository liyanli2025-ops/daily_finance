# v49：正文阅读视图与证据用途

把已存原文与模型阅读内容分开。原文、原始HTML/供应商分页、SHA256、失败记录和累计费用不变；不重搜、下载或购买摘要。沿用单期累计$1估算、每次65000字符、正常4次模型和最多1次条件补查。程序预算不是服务商硬账单上限。

## 这次实际做什么

1. 在评估、写稿、审稿及其费用规划中使用同一份确定性阅读视图。
2. 高精度识别独立广告标签、带明确界面的推广链接、订阅分享尾栏及平台作者介绍；移出的内容记录原文字符区间。免责声明、否定、反方、条件句不随尾栏删除。无法确定布局时保留原文。
3. 发行人公告与结构化行情完整保留。不自动缩短公告表格，不猜哪些历史行或脚注可删；复杂公告节选不在本版交付范围。
4. 评论栏目/自标评论只作署名观点，不能用来证明政策原披露、选举结果或最新收盘。标题单周而正文两日、以及混合领导层辞任/临时CEO与IPO重大说法的综述，进入待核线索，不向模型重复发送整篇正文；要另读原始依据，不能用同一篇其他无关句子蒙混过关。
5. 这些规则是有限的预警和用途限制，不是通用真假检测。单篇正常新闻、IPO报道、治理风险不会仅因出现关键词就被过滤；未命中不等于真实。被隔离也不等于已经判假。来源标为证据候选仍须原有事实评估和独立审稿。
6. 每次实际请求记录原文散列及送达区间。引用不得落在移出区间、拼跨省略标记或未送达部分。待核来源不能直接支持ready、covered或成稿引用；公司、五类变化和预期差检查使用相同约束。
7. 部分重要事件缺依据，继续交部分材料，不买更多模型回合强行写稿。真实选举和政策证据缺口不因清理广告而消失。

## 服务器操作

上传本包到 /tmp 后运行包内 run_server.sh：免费隔离检查、安装、保留维护暂停重启、免费读取已有5篇并生成正文筛选对照与续接预览。没有 --run，不执行任何模型、搜索、网页或TTS请求，不发布App、不恢复自动化。

合并包支持已知v47和v48基线，无需先装v48；其他本地修改会拒绝覆盖。安装需服务器自己生成与载荷及当前App签名匹配的离线验收回执。

免费结果在包目录 evidence-screening.txt 与 continuation-preview.json。先阅读正文筛选对照，重点确认两篇公告的单位/期间/脚注完整、Kitco免责声明与反方保留，以及两篇综述作为待核线索。不在本次安装脚本中安排收费续接。

已有input-capacity-v48续接标记沿用：如已经执行过付费续接，只返回旧结果，不删标记或创建另一条收费分支。未跑过则预览更新后的输入与累计预算。
