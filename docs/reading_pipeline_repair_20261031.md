- PDF/Office与不支持的社交平台在HTML读取前返回明确不支持原因，不把Instagram连接超时当财经正文。
- 三次URL尝试仍为零正文时，停止后续模型轮次，状态 `reading_pipeline_unverified`，先排查读取链路。最后一轮模型如果继续要求工具，也不再付搜索或网页请求后却没有模型轮次处理。

## 免费正文预检

安装本修复后，在backend目录运行：

```sh
sudo ./venv/bin/python -u /var/www/finance-daily/tools/check_saved_search_bodies.py --run-public
```

它只复用这次付费搜索已保存的候选，不调用Claude/Tavily、不生成报告/语音、不改App。最多检查3个链接、最多9个含跳转GET；优先本地同URL正文，已尝试URL仅允许缓存读取，缓存丢失不回退网络。其他URL必须此前未尝试，且继续服从失败台账；旧失败链接不重试。独占marker防重复运行。默认不带参数只显示零网络计划，--run-public是明确公共网页读操作，不涉及收费API。

无剩余候选或缓存时如实停止，不偷偷新搜。原始响应和结果只证明读取范围，不能证明选材重要、事实真或覆盖充分。免费正文预检至少拿到可用内容并核实失败类别之前，不启用下一轮付费模型试验。
