# v42：把统一生成入口改为听众需要的研究流程

本轮目标是可追溯、有经营依据、能说明判断边界的财经播客。不能从测试通过或模型自评推出“世界最好”“最准确”，也不能承诺收益。

## 从真实材料看问题

最近一次已上传的11月14日文字验收仍为partial_materials：93条候选，4篇正文；4只自选股的直接证据检查全部missing。v40补查新增6次搜索、12次网页HTTP，没有增加合格正文。累计估算$0.343412，不是新的费用。

当前存储的4篇是港股收盘报道、股价翻倍故事、某公司回购报道及财经早餐。它们不等于四只自选股分别完成研究；其中重大人员变动等说法尚未核到原始披露，不能照着标题宣称事实。

另一份历史失败审稿样本出现两种跳步：利润增速高于收入就认定经营质量改善；回购完成比例被用来推论股价支撑。这两项都缺必要依据。报告不能以有引用替代合理推理。

研究应分清利润表、现金流和财务附注；专业研究要求充分、可靠的合理依据。参考：[SEC财务报表入门](https://www.sec.gov/about/reports-publications/beginners-guide-financial-statements)、[CFA合理依据标准](https://www.cfainstitute.org/standards/professionals/code-ethics-standards/standards-of-practice-v-a)。这些原则用于研究设计，不为任何股票结论背书。

## 已落实到代码

1. **直接取得公司披露目录。** 当前A股自选股先查公司公告列表，每家公司最近20条，依原截止和用途时间窗筛选；没有用关键词搜索来冒充公告查询。先给模型标题、来源、发布时间与公告日，选中后才请求公告文本，最多2页，分页不完整不准入。它是东方财富披露镜像，不是交易所原件已核。
2. **接通业务与财务基线。** 复用已有ResearchHub适配器，每家A股额外最多1次业务归类、1次结构化财务请求。按返回的业务归类选择经营问题，未取得时只用通用问题，不按四个股票代码硬编码。财务基线包含最新已披露期和可用去年同期，保留原单位、累计/单季及镜像限制；没有公布日的行不作证据。读到同一家公司的当前正文后，将已取基线作为比较背景一同提供，不再下载。
3. **财务背景不能填新闻缺口。** 基线不能充最新收盘、政府原政策或本期新增公司事件。只有旧指标不能把当前公司核对变成covered；公告空目录也不能声称没有事件。
4. **观点要有可检验的链条。** 写稿同一次返回listener_cards：依据原句→经营/估值传导→另一种解释→期限→撤回判断的观察条件。依据必须逐字存在于真实已读来源；撤回条件短句必须同时出现在报告与口播。机器只核对存在和引用，不会证明推论正确；联合审稿负责核因果强度。
5. **每只自选股都有后续观察。** stock_followups覆盖当前App名单，正文必须出现该公司名称或代码。明确有证据还是不足、下一观察变量、下次该核对什么。不能用同行填成该公司的直接证据，不猜用户仓位/成本，不给保证收益或强制买卖。
6. **联合审稿增加五项听众要求。** 事实依据、因果强度、公司关联、时点/单位、反方与失效条件，各要给报告及口播原句。未通过保留稿件并停止，不自动付费修稿。
7. **有可读结果。** 每次保存同步生成listener-receipt.txt，列出实际正文、自选股缺口、后续观察和判断边界；与同一期结果一起导出，不再只交一长串JSON。

新协议只在新一期状态写入research_protocol=listener_research_v1。历史费用、截止、失败和started标记不升级、不删除，不把旧样本补写成今天的成品。v40/v41旧状态不强行套新输出结构。

## 检索与费用安排

四只A股的初始付费搜索由12项变成8项，另外4项改走披露目录。每家最多1次列表、1次业务、1次财务HTTP；选中的公告最多另2页。全部公开HTTP在发出前计数、保存started，失败不清零；原始JSON与摘要哈希留在本期证据目录。禁止重定向和自动重试，失败通道按已有持久记录停用；同一端点超时、连接失败或401/403后，本期其他公司不再重复撞该端点。重复成功请求只读本期捕获。

先取得这些公司上下文，再检查整批付费搜索与后续模型规划。公共请求共用max_body_urls×3上限和原研究时限；通道失败留缺口，不偷偷转付费搜索。其他8项全市场发现仍用Tavily；不是已完成全部全球官方来源直连。港股专属披露通道也未在本次新增。

模型仍正常4次，最多条件追加1次。增加分析字段会增加少量输入/输出，已纳入同一费用预测，不能据少4次搜索就断言总账单下降。没有另开付费运行，没有改1美元旧验收预算，也没有恢复定时生产或生成音频。

## 本次完成与剩余验收

本轮完成的是实际代码集成、回归用例与部署包。未在当前环境执行应用测试、联网验证新的直连通道或调用模型；不能宣称服务器可用率、成稿质量、费用目标已经达成。

停止继续扩展功能，按以下顺序验收：

1. 合并包免费隔离回归全部通过才安装；有差异或失败即停止，不覆盖服务器其他修改。
2. 免费预检看到source_plan，公司路径与费用规划正确，自动化保持暂停。
3. 用一次经明确核准的真实验收检查资料、观点和口播。先确认披露通道可访问、日期/主体/分页合格，再核对实际输入和预算。现有旧期不会自动重开；不以本次安装隐含授权新的收费样片。
4. 文字合格后，用同一份已审口播生成样音，听发音、停顿、数字、主线与重要条件是否保留；不再收费重写脚本。听感不合格只修语音环节。

内容通过的最低标准：重大事件有可靠出处或明确保留待核；四只自选股逐项有结论边界；事实与解释分开；统计期/交易时段/币种单位一致；重要观点能说出反证和下一观察点；没有利润/回购/解禁的因果跳步；口播听得出主线和关键条件。结构回归不能替代以上内容验收。
