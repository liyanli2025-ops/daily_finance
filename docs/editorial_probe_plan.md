## 给模型的六个案例

以下都是编辑测试材料，不是实时行情或对当前市场的建议。只能重组给定事实，不新增阈值、经营事实或因果证据。

1. 材料：前一已完成日线的指数在MA20/MA60下方、RSI14为25；当天若干科技公司刚披露利润增长，指数盘中反弹。原稿：“更像技术反弹而非盈利驱动，因为之前跌得多。”要求修正归因，保留有效的结构判断。
2. 材料：某股与板块当日同向反弹。原稿主张：“目前倾向该股随板块波动；若板块回落并带动它回落，则此解释被推翻。”要求修正判断与失效条件的关系，不编一个已发生的独立强势信号。
3. 材料：原稿已明确“14:08盘中相对昨收下跌2.94%；上一交易日日线收盘41.45元”。审查意见：“没报现价且并列昨收，因此数据不一致。”要求裁定是否应改，不为了修改而增加无用数字。
4. 材料：某工具不增加基础货币，但允许符合条件机构获得抵押融资，尚无效果数据。原稿：“所以不会影响市场流动性。”要求修正概念跨越，不把缓释目标写成效果已经实现。
5. 材料：三个成长指数上涨，关注股甲乙下跌；甲乙的行业属性未给，缺少板块排行和资金流。原稿：“资金已从防御板块全面搬向科技。”要求缩小推断范围，同时保留有证据的相对表现观察。
6. 材料：某指数日线高低点仍下移、低位动量且当天反弹；原稿：“未来数日我暂倾向下降结构中的反弹。盈利消息可以推动反弹；若其后完成的价格结构不再下移，原结构判断需要修正。这是当前倾向，不是必然。”要求评估是否有必要修改；不能因为缺少已证实因果而删除全部方向性判断。没有未来行情，不得判预测命中。

## 人工验收标准

第一项不再用过去跌幅识别当日驱动；第二项不能继续把符合主张的表现当反证；第三项承认原文口径可兼容；第四项分开基础货币、融资和交易流动性；第五项保留样本边界，不凭印象分类股票；第六项保留有条件的主观倾向，不改成必涨，也不抹成“无法判断”。

口播不逐项念六道题，不连报数字或接口缺口；须把结构判断、消息可能带来的推动、仍缺少的持续性证据接成连贯解释，并保留对应条件。修对这六例只证明局部编辑能力，不能代表完成整期分析、预测或音频验收。
