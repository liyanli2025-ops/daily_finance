# 播客资料使用范围：用户确认的方向

2026-10-25更新。本文记录后续实现要求，不表示这些能力已经全部实现。

## 当期资料池

资料收集服务于当天/当期播客生成。可以在生成过程中检索、读取、比较和补查，但不以建设长期个人知识库、不断扩大本地资料规模为目标。临时正文、PDF和检索索引应随任务完成与重试期限到期清理；成品报告、音频及必要引用信息与临时材料分开管理。

抓取窗口、资料有效性与存储期限是三件不同的事。当天分析可以用近期新闻、旧财报或较早研报解释业务背景，不代表需要永久保存原始资料。原先的7天滚动历史库用于补回采样列表丢失，现已改为按最近采集/见到时间保留24小时；旧财报保留原发布日期，重复作为当期参考不等于长期归档。具体实现与未完成部分见repair_roadmap.md。

## 外部资料库

优先评估能够持续更新的既有资料库、公开披露和研报接口。分析按当前自选股、实际业务环节和全市场问题检索，需要时读取相关原文；不整库镜像，不把搜索高亮或AI回答冒充原文。

腾讯财经在IMA更新的研报库是用户提供的参考思路。不能据此推定其使用OpenClaw或某个抓取接口，也不能把用户拥有IMA账号、订阅该库或手工配置凭证作为当前工作的前置条件。

已核对IMA官网提供的官方接口包1.1.10：包含知识库搜索、库内条目搜索及媒体访问信息读取。官方文档同时存在成功但不提供原文URL的分支。因此，接口存在不证明腾讯财经这个具体订阅库可被外部程序访问；本次未以用户身份完成权限或研报正文验证，不能声称接通，也不能笼统裁定无法实现。

官方入口：https://ima.qq.com/agent-interface
官方接口包：https://app-dl.ima.qq.com/skills/ima-skills-1.1.10.zip

来源评估结果应区分：已实测可读原文、只有目录/摘要、需要尚未具备的授权、当前不可用。某一候选渠道受限时继续评估其他现成来源，不为了接入某个平台而要求用户折腾账号。
