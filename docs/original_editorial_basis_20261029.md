## 保留与调整

| 原版要求 | 在原基础上的处理 |
|---|---|
| “所以我该怎么做” | 保留：优先看什么，条件满足后参与、等待或回避，什么改变原计划。不强迫每段买卖命令 |
| 一条主线、自然过渡、结论先行 | 保留，一条主线最多三个相关问题；不强造因果拼接无关新闻 |
| 早报、晚报、周末不同任务 | 将共享节目定位补回当前正式报告及口播请求；即时更新按实际时点，不装成开盘前 |
| 基本面、资金、技术、情绪联动 | 用已有证据交叉解释，缺失不编。同源技术指标不算独立投票；旧固定权重没有验证，不作为定量模型 |
| 产业链传导、分歧、情景、风控 | 保留机制和受限环节，有证据才挑战共识；保留有边界的主观倾向，不一律观望 |
| 专业但通俗、敢给判断 | 通过重点筛选、推理与反证体现资深感，不靠身份台词、反复称呼或口头禅 |
| 固定三建议、逐股目标价/仓位/概率 | 改为材料允许的判断和条件；不知道用户成本和仓位就不凑比例，不把未校准数字当胜率 |
| 固定字数下限、投资课堂、天气开场 | 按有效内容决定长度，用户目前上限20分钟；知识从本期问题自然解释，不为填栏目插课 |
| 只给口播前1500—2000字精华 | 继续提供完整正文和反证，不恢复截断 |
| 话题去重 | 本期重复合并继续保留；旧跨期课堂去重仍要求“必须全新话题”，未盲目接回。持续主线有新变化时应继续分析，不为求新换题 |

## 已改实际链路

`editorial_policy.py`补足决策价值、传导路径及连贯聊天式口播，增加共享的早报/晚报/即时更新/周末回顾定位。

`ai_analyzer.py`实际使用的`_build_editorial_report_prompt`注入对应定位；周末标签与生成上下文一致，不据此推断所有市场休市。未靠修改不再使用的旧大提示词冒充生效。

`podcast_generator.py._generate_ai_podcast_script`继续以完整报告为唯一事实材料，并注入同一节目定位；即时更新优先于周末回顾。不增加模型调用或新事实。

`podcast_script_cache.py`把节目定位规则和报告标题纳入签名，避免标题已变为即时更新却沿用早报缓存。

## 更正上次小测的解读

1041字符市场模型小测是独立编辑题，**没有走正式报告或播客请求**。题目要求纠正误用并解释模型，其输出偏模型讲解有任务本身的原因。能判断基础解释是否正确，不能据此判定正式节目已经像课程，也不能证明新要求下的听感已通过。

后续应按真实当期报告→正式口播链路验收重要变化、观点依据、反方、条件性应对与听感。不再重复残差编辑题来调整整期节目；已执行的一次性脚本、输入和标记保持不变。
