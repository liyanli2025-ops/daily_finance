# 默认关闭失败后的额外付费调用

2026-10-29源码更新，尚未部署。服务器最后确认版本仍为v11-r2；自动任务保持暂停。

## 行为

- `MODEL_HTTP_RETRIES=0`：默认每次逻辑模型调用只发送一次HTTP请求。网络错误、429、5xx及截断均不自动重试。显式设为1才允许原有有界重试；仍逐次检查维护暂停、自选股变动和调用预算。
- `REPORT_AUTO_REPAIR_ENABLED=false`：报告审查不通过时保存正文与问题，转为待人工编辑并停止发布，不自动整篇重写再审。显式启用才走原有修稿路径。
- 截断回复保存可见正文和结束原因，标记不可发布；不保存供应商隐藏思考、认证头或原始错误信息。未返回可见正文也会明确记录。

这不是“整期只调用一次”：分析、取材、审查、口播仍是不同阶段，原有全局预算继续生效。一次失败请求也可能计费；关闭自动重试不是费用保证。独立验收工具已有的一次POST与永久标记不改，不允许重跑旧试验。

## 验证与下一步

离线测试覆盖默认值、网络/限流/服务错误/截断均只请求一次、截断正文留存、严重问题不触发修稿；显式启用重试的测试继续验证暂停和自选股变化会阻止第二次请求。未调用真实模型或TTS。

本次只解决重复费用路径，不代表分析或口播质量通过。仍需处理已保存分析稿的过度归因，再以有限的新验收检查实际效果。合并下一部署包时须接受已确认v11-r2的精确基线，不能跳过服务器差异校验；不修改模型、密钥或自动恢复调度。
