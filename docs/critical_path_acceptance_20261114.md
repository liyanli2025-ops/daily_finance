# v47：先验证正常产出与失败止损，再放行收费续接

## 发布边界

本版替代v46的待验收交付。只有隔离验收成功、且覆盖规定的完整流程与故障情景，安装器才会安装与实际App源码指纹绑定的准入回执。收费续接在创建started标记前验证该回执；代码变更、回执缺失或不完整均不能沿用旧结果。

测试不是新闻事实认证。模型端返回确定的协议样本，搜索适配器返回空目录，公开网页设为不可用情景，公司目录、公司基线、指数和公告分页使用用户提供的真实原始HTTP快照。所有实际socket连接被外部阻断。真实选材、公司适配器、正文分页解析、模型请求组装与用量核算、证据约束、写稿与审稿检查、口播缓存保存仍执行生产代码。

## 前置审查实际修正

1. 同期续接除了旧113次公开请求、16次搜索、1次模型和截止，还恢复原4份财务背景的原ID、正文和期间。只复制计数而遗漏材料池会使后续明确请求基线时取不到原资料。
2. 续接预览同时核对剩余模型预留、必要阶段输出额度与已知评估输入。费用够不代表其他额度够；未知新正文仍会增加输入和费用，不能保证一期必定完成。
3. 阅读开始即保存reading阶段；读取中断不再残留agenda阶段，避免错误诊断与误续接。
4. 全部App Python源码绑定准入，不维护容易漏文件的签名名单。安装器绑定测试文件、真实样本、运行载荷和自身检查脚本。
5. 真实选题存在S13央行与S30选举两个未交代线索。旧单元预期只写S30，已按真实快照修正；没有自动重分类或把它们当已核事实。

## 验收情景与通过含义

- 正常：真实公司目录→选中宁德时代公告→实际读取三段供应商文本→10318字逐字拼接→实际网关4次模拟HTTP→证据评估→写稿→审稿→保存文字及已审口播缓存。
- 原v45失败：保留原result、模型回复和113份HTTP快照，实际续接阅读；没有适用正文的重大事件及未说明的选举线索仍保持缺口，不购买写稿或审稿。
- 所有正文不可用：在评估前停下，不能把派生行情当成已读新闻。
- 模型402：已读正文、费用预留及失败回执保留，无自动重试。
- 错误引文：实际约束降为缺口，不能进入写稿。
- 输入超限：在模型HTTP前拦截。
- 读取中断：保存interrupted及reading，不发布。
- 落盘失败：在外部模型HTTP前停止。
- 真实失败续接再次调用：返回原子目录结果，不新增模型、搜索或网页请求。
- 具体重要议题未处理：保留明确缺口，不能用笼统宏观分类放行写稿。

这些检查不能证明外网当天可读、热点发现充分、模型判断正确或节目好听。软件准入通过后仍需在服务器免费核对环境，再进行一次原预算内的明确收费验收；不增加预算、不新开一期绕过失败。

## 安装与运行

安装包支持已知v45-fix1与v46源码，其他改动停止覆盖。保留服务器.env、密钥、模型和计价、原$1估算预算、数据库及暂停状态。安装器先做私有备份与健康检查，失败回滚代码。

默认run_server.sh只进行禁网隔离验收、安装、原资料回放与免费续接预览。没有自动收费命令。旧续接子目录名称保留agenda-continuation-v46，不能通过升级重置started或重新扣费。

准入范围仅为当前App及专用验收工具，无Skill接口变更。
