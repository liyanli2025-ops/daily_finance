原因包括输入与规则设计：把供审查用的纪律与真正分析放在同一层，口播规则再追加整套归因审核条款，强化了复述边界的倾向。修订稿本身也有重复限定；不能把问题都归给模型。

## 本轮改动

1. 重写正式口播要求：用已有的具体变化/分歧开场，贯穿一个听众关心的问题；以具体例子推进解释，再落到短线取舍。长短句交替，减少书面词、连续反问和固定模块，不靠虚构资历、夸张或制造焦虑吸引注意。
2. 不再向口播追加整套分析归因审查清单。已有事实保真、不得新增交易建议、条件/对象/期限不改等规则仍保留；正式口播审查并未取消。
3. 只有明确的“## 编辑说明（不朗读）”段落才分流到后台备注；不按“没有证据/不能判断”等词批量删除正文。后续正式分析章节仍保留。编排引用只允许来自分析素材，不接受后台备注作为事实依据。
4. 已见的明确后台口吻加入本地泄漏拦截，保留原稿停止后续调用，不自动付费重写。普通来源归属与真实不确定性不拦截；词项拦截只是低成本格式检查，不证明口播自然或正确。
5. 数字可以择要省略，但保留的值/单位须准确。关键支持、反方和条件不能因吸引力而删改。写作要讲透有用内容，不设置新最短时长。

人工示范见macro_listener_sample_20261029.md。示范用于明确编辑目标，不是新模型结果；历史样稿不是实时建议，未生成音频、未测真实时长。没有新增模型阶段或付费请求。
