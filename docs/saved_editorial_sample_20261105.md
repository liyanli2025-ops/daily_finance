# 从已存资料进入一次完整文字样稿验收

## 本轮决策与结束条件

优先交付一份可阅读的文字样稿，再按实际稿件决定音频；当前暂停扩展一般采集适配。v29服务器安装、258测试及同源回放已通过：12快照匹配，三份标题误拒正文恢复5266字，七项笼统预算延期被拒；推广稿和美债政策用途检查生效。尚缺港股、部分自选股、政策原披露及主线研究；不宣称全市场覆盖或取材合格。

本期收集已花12次模型、11次搜索、18次网页尝试；服务商实报输入412990、输出9258token。写稿是独立阶段，旧用量全部保留，不删除或替换任何旧marker/结果。v29已恢复的文字与老模型送达账本分开。

本轮只准备一个**历史文字样稿**：沿用2026-11-05T08:32:25.702638截止及真实App名单，最多一次写稿6500输出token、一次审稿3500输出token、累计130000输入字符、480秒；0重试/自动修稿、0搜索/网页/TTS，无App报告写入、无生产服务重启。最多两次POST是本次文字验收上限，不改变默认取材或报告预算。字符、预留输出与次数均不是金额上限。

写稿后有具体原句、来源及审查意见就进入人工内容验收；即使模型pass也不直接发布或生成音频。事实错误、时段混淆或无依据判断须先修正；其他一般网站兼容问题不阻碍本轮文字样稿。若输出失败，保留已有可见文字和全部用量，不自动另开试验重跑。

## 实现与生产边界

- `tools/saved_editorial.py`：通用的已存资料准备、显式尾部隔离、长正文近重复识别、写稿与审查协议；只用原文，不填补本期结论。
- `tools/run_saved_editorial_once.py`：默认免费预览；核对封存资料、当前App名单、路由和v29源码，显式`--run --input-sha`后才执行。使用现有gateway的路由、请求格式、完整返回判定和用量账本，复用正式REPORT_POLICY/REVIEW_POLICY；维护暂停只读保留，收费仅在显式隔离进程进行。
- `tools/editorial-case.json`：本轮资料身份封条。通用入口不写死新闻、股票或解析结果；换资料须明确提供新的case配置和匹配回放材料。
- 既有`PrimaryReportService`的取材完整性、新鲜度、质量与维护暂停检查保持原样。此入口不将不完整期升级为可发布报告，不清除停用记录，也不调用旧行情补全、正式scheduler或TTS。

准备时比对原result、研究检查点、材料正文、12个HTTP200快照的URL/字节/哈希/截止。v29回放JSON要求与已上传附件的完整字节SHA匹配。推广或质量待审正文不进样稿；近重复转载作为备选保留在排除清单，不计独立证据。显式推荐/引流尾部与密集指标目录只在新样稿输入中隔离，保存原文字哈希和区间，原正文与回执不变。该边界规则不宣称适用于所有网页。

新的`sample-`引用ID属于样稿资料命名空间，原ID和新恢复来源另列，不冒充已送达。每条引用需有对应原文和稿件原句；该机械检查不能证明引文确实支持结论，仍由审稿和人工阅读判断。发布时间、交易日、媒体转述与原披露的限制交给写稿和审稿双方，避免机械把发稿较新当最新行情。

## 使用

服务器只解压小工具包到`/tmp`，无需运行安装器或覆盖生产文件。保留`/tmp/daily-finance-v29-offline-review.zip`以及本期原episode。

第一次：一次运行包内`test_saved_editorial.py`，随后运行入口默认免费预览。预览会给出来源、排除清单、缺口、历史截止、当前路由、最多两次调用边界和输入指纹；同时封存私有输入。预览期间仅查App数据库，不调用模型或外部网络。

第二次：使用未过期的预览指纹执行`--run --input-sha ...`。相同写稿试验永久marker防止重复扣费；执行期间资料/名单/源码/配置变化会停止。结果写入`backend/data/diagnostics/saved-editorial-v1`，`draft.md`为人读文字，`draft.json`含引文索引，`review.json`含具体审查意见。失败也尽量保留可见回复；不会把截断JSON当成通过。

导出：入口单独`--export-review /tmp/daily-finance-editorial-review.zip`。仅导出文字、审查、样稿来源及用量，不导出私有输入中的环境或连接指纹。已有同名导出停止，不覆盖。不要上传整个项目、数据库或.env。

本轮新增16个离线用例，覆盖正文/引文身份、转载、尾段、审查矛盾、旧marker、源码变化及模拟两次POST上限。尚未在本环境执行项目测试或预览；需服务器一次验证。不声称已生成文字或音频；0新增付费请求。本工具不被Skill调用，无Skill接口变更。
