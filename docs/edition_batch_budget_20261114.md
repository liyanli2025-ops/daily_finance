# v34：在搜索之前核算整批费用

本次收尾只处理已确认的预算缺陷，并合并v32/v33已有选材更新。正常4次、条件追加1次模型；不改模型、凭据、金额接受状态、暂停状态或正文/输出容量。

## 行为

- 初始搜索批次与补搜批次先校验全部任务，再按去重后的真实请求数量计算整批搜索费和所有未请求的必要模型阶段。预算不够先记录原因并停止，没有任何搜索预留或HTTP。
- 拟执行条件补查时额外保护patch_assessment；没有新正文仍不购买一次无用评估。未知新目录/正文取得后会继续改变预测，因此启动检查不保证未知整期都能在金额内完成。
- request_for实际请求没有cache_control时按普通输入价规划；显式缓存或旧账本的未知输入仍取输入/缓存价格最大值。不假设命中缓存折扣。实际完整Anthropic回执继续按各类token计入同一账本，失败/未知用量保留原预留。
- 已知系统词和正文按UTF8字节保守规划；未来模型结果按其输出token额度另留25%输入余量。后者是规划约定，不是精确token计数或任何JSON/中文转换的数学硬界。真实稿件到手后使用实际请求字节重新计算。
- 免费预检同时展示4个必要阶段、整批搜索成本、未定价的未来资料和阻止项。--price-scenario仅使用内存配置副本，强制费用未接受，不改变真实搜索/模型/音频/暂停设置，也没有--run。

## 已做与待做

本地一次36条纯离线回归通过；完整应用88条需使用服务器现有venv在禁止socket连接的隔离副本运行。本地未安装应用依赖，没有冒称完整套件通过。无新模型、搜索、文章GET或TTS。复算数值来自2026-11-14公开价格情景及已上传历史脱敏资料，并非服务商账单。

空资料四阶段$0.424476 + 搜索12×$0.008 = $0.520476。历史92候选/8正文（尚无新选题和稿件）规模同口径规划$1.055944。两者都不证明实际花费；空资料启动价尤其不含未知正文，也不含条件第五次。不能为了通过$0.50检查而修改价格、偷删来源、假设缓存命中或开放免费额度。

## 服务器操作

合并包可从已知v31/v32/v33源码安装，内容差异必须停止；保留自动化暂停、配置、数据库、私有备份机制及真实失败账本。先隔离验收88条，安装器要求匹配当前包文件的成功回执。包内README给出一次复制即可运行的命令：解压→隔离验收→安装并重启已有服务→仅内存价格情景预检。任一步失败停止后续。无需重下载Git仓库、依赖或上传历史整套工程。

安装不代表允许收费或已生成一期报告/音频。用户仍没有接受单期金额；免费试算输出即使fits_money=true也不能绕过暂停、费用接受与搜索开关。
