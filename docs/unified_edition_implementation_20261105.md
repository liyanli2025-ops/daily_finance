# 统一一期编排：实现与隔离验收

状态：代码已编写，未运行项目测试、未部署服务器、未发起收费请求。以下为实现范围，不是质量或调用成本已现场验收的承诺。

## 已接通的主路径

`SchedulerService.generate_morning_report/generate_evening_report` 均委托 `_generate_unified_edition`，原早晚报各自采集、分析、再写口播的主体重复逻辑已移除。现有手动触发 API 也经同一调度服务；免费预检阻止时返回条件清单，不先声称生成成功。晚报保留当天早报供复盘，原报告仅作旧判断对照，不当新事实。盘中缓存、行情维护、回测与信号追踪仍是各自后台能力，不计作本期新资料或本期预算已覆盖的任务。

一期状态在后端 `data/editions/edition-<ID>` 保存，包含动态事件、所有候选、实际全文、读取失败、原始可见模型回复、已送入完整模型请求的来源 hash、文字及口播、审稿意见、预留用量及实际 HTTP token 回执。同一期 ID 贯穿网关记录；服务失败也更新可读 `receipt.txt`。

正常路径为 4 个模型阶段：一次选题、一次证据检查、一次同时写文字和口播、一次联合审稿。有明确缺口可在同一期内补查并追加一次证据检查；全期至多 5 个模型请求预留，不能清失败标记、改试验名或从头重采来补足。没有正文、补查没有新增全文、重大事件仍缺则提前停在部分资料。

程序执行的是整批查询/读取，不为每个 HTTP 请求再调用模型。当前 HTTP 工具按顺序执行以复用现有共享计数和缓存，不声称已经实现并发加速。补查新目录的候选以同一事件为范围批量尝试，不机械接受第一条；仍受正文 URL、搜索、输入和时长边界约束。

## 重要性与证据

基础检索保留市场和实际 App 名单，另有国内、国际重大动态发现，未把“中期选举”写进运行时固定词表。选题模型必须交代每个候选归于哪一事件或为什么排除；证据检查不得删掉已列的重要事件。发现新重要事件可追加，证据未就绪则阻止成品。类目中有其他正文不再消除该事件缺口。

主体匹配、推广提示、政策原披露/评论和最新收盘用途限制沿用原 helper。自选股 covered 必须有主体匹配正文及逐字依据。有限检索未发现重大公司事件可以明确说明范围，不能由链接失败推出没有新闻。

原研究说明、报告编辑政策、早晚报定位、口播风格和事实/判断/限定语三类逐字对照继续复用。联合写作输出完整报告、口播和各自事件映射；程序核对逐字引文、来源 ID 与重要事件映射，联合审稿检查事实、因果、时段、遗漏和听感。结构和引文存在本身不证明新闻真实，也不能保证模型选题无遗漏。

## 费用与失败处理

生产配置没有被交付包改写。新增配置默认 `EDITION_ESTIMATE_ACCEPTED=false`；模型各输入/输出/缓存单价、搜索单次估价、一期美元估算边界未明确配置时，预检阻止执行。API 不具备维护暂停绕过；默认自动重试和自动修稿仍须关闭。

价格键是实际路由的 `provider/model`，四种单价以每百万 token 美元计。价格不由程序从模型名猜测。UTF-8 字节按一字节一 token 是保守规划约定，不是真实分词或账单硬保证。程序保护后续写作/审稿预留，失败或未知用量不退款重置，实际 token 单列；美元估算不是服务商硬金额上限。模型、搜索与音频尝试分列，不把各自次数混为模型次数。

音频只接受与该报告完全匹配的已审口播缓存，缓存缺失就停，不再调用写口播或审口播模型。统一路径仅尝试 Edge 语音，每个已审主题一次，不自动重复或切换收费 TTS；每次合成前落盘计数。解码、时长和背景音处理沿用已有实现。音频失败保留已审文字，明确重做音频只进入这一阶段。目前续审及音频续接同样受原期两小时有效期、配置/名单指纹与剩余活动时长限制；过期任务保留回执，不自动收费重启。旧报告若没有新一期的已审缓存，也不能借重做音频触发模型补写。

跨进程锁和本日/类型永久标记防止重复扣费，`force` 不清它们。完整审稿已返回却内容不合格时不允许重购同一响应；只有未完整返回的 review，可在原一期剩余额度、原截止/名单/配置条件下明确续接。402/网络失败不自动重试，继续占用原预留。更换配置、源码、名单或越过有效期则停止。

## 可读入口

- `python -m app.edition_preflight`：与生产同一服务的免费本地预检，没有 `--run` 参数。
- `GET /api/reports/generation/preflight`：列名单、阶段、基础查询、路由元数据、价格边界及阻止原因。
- `GET /api/reports/generation/runs`：最近任务、状态与缺口。
- `GET /api/reports/generation/runs/{id}`：来源、候选、稿件、审稿及费用回执的 JSON。
- `GET /api/reports/generation/runs/{id}/receipt`：可在浏览器直接阅读的全文与进度。
- 原报告/音频触发入口复用上述主路径；`POST /api/editions/{id}/resume-review` 只续原期未完整返回的审稿，不新取材或重置预算。

尚未改前端页面；这些为真实后端接口，不是已上线 App 功能展示。没有迁移数据库结构。
