# v28：候选用途与独立新一期验收

用户回传确认服务器 v27（388959d）已安装，180 用例通过；离线回放验了 9 份快照，模拟第二次无新增证据的无效 finish 停止，并能本地补读 MUFG 剩余 2965 字。真实旧结果仍是 stalled_no_new_evidence，尚无合格底稿或播客。

## 通用改进

- 搜索、候选反馈和正文用途判断共用规则：ahead of / set to 等决议前瞻保留作背景，不填已发布政策缺口。已发布决议附预期措辞仅标为待读核对，避免一概丢弃。
- X、Twitter、Threads 加入精确域名匹配；社交线索留在原目录，主新闻 HTML 阅读器不请求这些页面。公众讨论仍走专门工具，评论用途检索不增加排除域。
- 收盘任务优先展示完成时段摘要；滚动稿保留供模型选择和正文核对，晨报不能代替结算。排序不证明事实、来源身份或交易时段，也不自动读取第一条。
- 行动菜单展示用途说明；依据动态范围、名单和实际回执重算，未硬编码旧期候选 ID、公司或日期。

## 新一期入口

`tools/run_fresh_collection.py` 默认仅做本地免费预览，复用已有验收执行器的指纹、维护暂停、独占 marker、零重试、用量与导出边界。新一期封存当前 App 名单、当前截止时间、当前配置的预算和源码；不复制旧正文、恢复旧状态或把旧周末期冒充今日。

独立目录为 `data/diagnostics/fresh-collection-v28/`。历史旧试验保留：19 次模型请求、1368376 输入字符、62700 预留输出 token、12 次搜索和 17 次网页尝试。预留输出不是实际输出或金额。新预算单列，新的 0 次请求仅表示新一期未执行，不抹去旧用量。

旧搜索诊断 HTTP200 仅作为同账户、同配置、明确审阅源码演进和同一 HTTP400 停用文件的窄范围进程许可；不会删除停用文件或恢复生产搜索。每次重验被冻结的结果、输入、marker 和台账；其它路由照旧拦截，新失败即撤销许可。旧诊断不是今日联网验证。历史搜索源码从原诊断到当前 v28 的三处变化均明确绑定。

免费预览指纹有效两小时；之后先重新预览。付费入口仍是同一脚本显式 `--run --input-sha`，本轮安装命令不含它。启动后 marker 永久保留，不自动重试；结果可用同脚本 `--export-review` 私有导出。免费预览会写诊断输入文件、读本地 App 数据库，不发送模型、搜索、网页或 TTS 请求。
