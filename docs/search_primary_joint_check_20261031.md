## 免费真实材料回放发现并修正的通用问题

1. “美股收盘：三大指数……”先命中了A股的“三大指数”词，造成美股误分A股，挤掉真正A股综述。现在先识别明确美股收盘，再识别A/H。
2. “港股行情收官……反弹”的口语标题未识别；只有正文也有收盘/收市线索时，才将这种标题作为综述阅读线索。
3. 帖子里的“要加息了吗”被当政策变化排前。参与者材料现在先标为讨论，不能靠标题关键词升级为已发生政策/行情；引用的旧原帖不替短回复获取经营数据标签。
4. 旧流程仍给每只自选股的季度披露提前占初读位置。取消这一自动保底，财报回到统一问题议程和可补读参考，不先于当期宏观、市场、产业变化逐只占位。
5. 增补中文采购经理指数、行业出货/报价/融资等一般阅读线索；多股行情和集体回应不因含业绩词一律误作普通单家公司报告。计划/拟议仍属于预期线索，不是已经实施。

讨论排序仍是透明的词项线索，不是成熟的语义主编、真假识别或预测模型。初读覆盖不等于模型实际读过；完整来源目录及其余正文仍可检索/补读。不再用本轮初读数量证明信息充分。

## 如何运行（安装新版源码后）

资料包格式见`search_primary_collection.py`及对应测试。必需字段为：

```json
{
  "owner": "finance-search-primary-v1",
  "collected_at": "2026-10-31T12:09:36+08:00",
  "hours": 72,
  "watchlist": [],
  "search_receipts": [
    {"query": "实际执行的检索词", "checked_at": "2026-10-31T12:00:00+08:00", "status": "searched_not_exhaustive"}
  ],
  "articles": [
    {
      "title": "实际报道标题", "url": "https://example.com/article/1",
      "source_name": "实际发布来源", "body": "实际取得的正文，不是模型摘要或搜索片段",
      "body_scope": "visible_body", "published_at": "2026-10-31T09:30:00+08:00",
      "publication_precision": "minute", "observed_at": "2026-10-31T12:00:00+08:00",
      "lanes": ["global_policy"]
    }
  ]
}
```

这是字段示例，不能拿占位正文或旧日期运行真实采集。日精度日期只写YYYY-MM-DD。支持主题为a_market、hk_market、us_market、global_policy、commodities、industry、company_event；主题覆盖是导入声明，须人工核查，不能作为自动通过标记。

安装后先做零网络能力预览：

```bash
cd /var/www/finance-daily/backend
sudo ./venv/bin/python -u -m app.primary_collection_check
```

有实际资料包后免费预检：

```bash
cd /var/www/finance-daily/backend
sudo ./venv/bin/python -u -m app.primary_collection_check --input /tmp/实际资料包.json
```

只有部署并准备有效的新资料、确认预览后，才能以同一输入文件和其SHA显式增加`--run-public --input-sha256 实际SHA256`。这不会执行模型；其输出仍需人工验收。当前服务器未安装本版，不要直接运行以上新模块，也不要重跑旧付费验收脚本。
