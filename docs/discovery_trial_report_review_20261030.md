## 实质问题

1. 报告将7400亿美元资本开支与两条“未读正文”的目录标题称为“相互印证”，又用东山精密目录标题充当反证，甚至出现未转换且格式错误的[N:C0031 ...]。目录是导航，声明未读不能使它成为支持或反证；即便两条都已读，总支出与现金流/股价反应也非逻辑上的互证。先核查是否实际触发了补读，不能假定模型一定没用工具。
2. 牧原“盈利取决于猪价，而不是降本”是错误二选一。原文明确说成本从年初约12元/kg降到9月略低于11.5元/kg，但没抵消售价下跌；合理结论是降本缓冲了压力，目前仍不足覆盖售价下降，未来还需同时看售价、成本、销量结构和屠宰等业务。不得由价低于成本推出降本不重要。
3. 医药/白酒逆势不能证明只是算力链内部出清：原文同样说明全市场超4600股下跌。可判断科技更弱、消费局部逆势；业绩落差/估值重检可保留为有边界的假设，但不能声称这些证据已经排除了系统性风险偏好变化或区分了原因权重。
4. 原报道列出石油/消费板块涨幅，不是指数成分贡献分解。可说这些板块表现靠前，不能直接当成已证实的恒指上涨驱动。恒科落后说明科技参与弱，不足以单独判断恒指反弹能否持续；其他权重方向可能支撑指数。这里不能靠资金流缺失一律禁止轮动假设，而应限定所回答的问题。
5. next-session判断与metadata失效条件不一致。“当日无止跌证据”是截至收盘的观察，不会由未来行情推翻；“后续几日仍弱”才是假设。强制放量收复当日跌幅再形成更高低点，是另一种更严格的趋势确认规则，不是短线反弹必需条件。中东风险线索也不是自动反证，counterevidence字段应对应具体claim。
