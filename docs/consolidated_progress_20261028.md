## 本轮新增

1. **标准市场模型。** 从已有日线计算“个股日收益 = 截距 + beta × 同市场指数日收益 + 残差”。A股基准沪深300，港股基准恒指。先用120期估计，随后20期留出检验，再观察最近5期；不拿后两段重新拟合，不搜索最有利窗口。
2. **检验结果约束输入。** 留出期误差与“个股收益等于指数收益”的简单基线比较；未优于基线只保留失败诊断，不向分析提示词提供最近残差或系数。缺146个同日期收盘、个股成交量、已核实复权口径则返回缺口。无需另一次采集。
3. **写作和审查同步。** 不把R²叫准确率，不把正残差当公司利好、未定价或未来涨幅；与技术指标共享价格输入，不算多票证据。口播只在改变判断时引用，避免读系数表。
4. **前端实际修复。** 修复主题颜色字面量、导航选项位置、空值判断、错误样式名和原生样式中的web字段；保持strict。原生播放器改用轨道实际布局宽度计算拖动位置，避免以宽度1导致跳到结尾。
5. **纯计算诊断不启动全套服务。** services包兼容原导出名，但延迟加载。只读市场模型回放不再为了导入数学函数加载调度、配置和音频模块；CLI可直接输出JSON。
6. **合并发布工具。** 严格针对已确认editorial-flow源码基线及其暂停补丁，包含此前未安装的证据范围审计、修稿一致性、口播保真、相对强弱及动态自选股准备。安装器要求现有暂停标记，settings必须为空，`.env`字节保留；拒绝未知差异，不覆盖测试、主数据库、venv、其他项目或前端静态根。重启验收还要求scheduler=stopped、automation_paused=true。

市场模型属于成熟的统计描述方法，可参考[MacKinlay的事件研究方法综述](https://www.bu.edu/econ/files/2011/01/MacKinlay-1996-Event-Studies-in-Economics-and-Finance.pdf)。这里**没有**完成事件因果识别、显著性检验或可盈利交易策略；也不是加入无风险利率后的完整CAPM。20期留出期很短，不证明长期有效。前复权个股与价格指数仍受提供方口径限制，不声称独立核实的分红总收益。
