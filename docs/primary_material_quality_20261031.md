# 主资料质量与定向补查（2026-10-31，未部署）

本轮继续改进主动取材至报告路径。结果是更完整、带具体使用边界的报告输入，尚未生成 AI 报告、播客或音频。

## 改了什么

新增 `primary_material_quality`：对正文中的明确购买口令、周边商品加购买动作、多项互动投票作非破坏式提示，返回原始字符区间。保留原文、反方信息和 SHA，不自动切掉“推广之后的全部文字”。普通价格、机构买入评级、订阅收入、风险声明本身不触发提示。启发式可能标记报道引用的广告，也会漏掉其他形式推广；无提示不是“质量通过”。

提示进入 `EpisodeWorkspace` 材料元数据，因此取材模型和本地正文检索/补读都能看见。取材协议要求优先换来源、不把口号当事实。`primary_report.prepare` 重新计算每份正文的提示，并把 `material_followup` 同时交给免费预览、写作和审查；不接受输入自己声明“已干净”来跳过检查。

显式报告生成在读 App、行情、创建生成 marker 和模型调用之前检查 `body_quality_review_required`。存在提示则以 `primary_report_body_quality_review_required` 停止，原有生产暂停检查更早执行。本轮没有添加强行放行开关；保留原材料待人工判断，选择合适的独立替代稿或暂不选该稿后再重新预览。此约束仅用于新主资料显式报告入口，旧 scheduler 没有自动切换。

补查计划依据输入声明/模型底稿中的实际证据 ID，列出缺正文、疑似推广需替换、只有短市场快讯需核驱动的问题。每项标 `executed=false`，不自动买搜索或启动循环；单家公司材料不会因正文提到芯片就自动变成行业覆盖。声明了方向也不是编辑验收，`coverage_verified` 始终为 false。真实 App 名单仍须在公司定向取材前核对。

显式主资料接纳记录增加 `editorial_notes` 与 `short_text_hint`，让作者归属、交易日、预测边界跟随输入进入写作。它们是外部备注，不能当作指令、事实或免责凭证。

中国银行移动金市分析页增加严格主机/路径/文章容器/显式时间字段解析。保留作者免责声明，网页没有时区便只用日精度；不由 URL 日期、搜索摘要或机器所在时区猜发布时间。模板不匹配照常停止。

## 怎么使用

在项目自己的 backend 运行环境，对一期真实主资料 JSON 执行：

```bash
python -m app.primary_report_check --input 本期资料包.json
```

这是免费的本地资料预览，不读 App、不联网、不生成稿件。重点看 `body_quality_review_required`、`material_followup.body_quality` 的原文区间与 `material_followup.tasks`；有短讯提示就继续核主线，缺正文就补具体来源，不把建议列表当实际查询结果。作者备注保存在 `context.intake.accepted[].editorial_notes`，同写作上下文传递。

本轮完整正文和原始响应属于私有、有时效的工作集，不打入公开源码包。公开交付为来源清单、局限、提示和代码；用户无需为了审阅结果先执行命令。免费预览中的本地 `automation_paused=false` 只表示本地没有维护文件，不能推断生产恢复。
