## 五类变化怎么进入主流程

| 范围 | 实际行为 | 证据约束 |
|---|---|---|
| 宏观政治 | 两个原有宏观检索槽分别覆盖已公布政策和英文选举/关税/央行/冲突线索；每个政治标题逐事件归类或说明排除 | 选举等具体议题不能被通用“国际宏观”标题吞掉；标记只是线索，不是重要性或真实性认证 |
| 行业变化 | 保留产业供需检索，另一原有广域槽改为产业链、商业化与竞争；使用实际业务归类的行业名检索，可发现未提自选公司名的同行变化 | 不猜上下游公司名单；技术突破不自动等于可量产或盈利；行业结论仍需读正文 |
| 公司经营 | 公告目录以外，每只自选股单独检查订单、客户、供应商、产品、产能、事故与停产；即使有财报公告也不跳过 | 同行正文、旧财务基线不充本公司本期变化；必须实际向模型提供正文且主体匹配 |
| 治理与风险 | 每只自选股另一个检索任务检查管理层、监管、调查、诉讼、融资及股东行为 | 区分传闻、立案/指控和裁定，计划与完成；无结果仅表示有限范围未选出实质事件 |
| 市场变化 | 把既有腾讯带日期指数报价、经新浪目录和腾讯逐股带日期报价计算的A股样本涨跌分布接进同一期 | 日期、身份、价格关系与至少95%可比覆盖门槛；不足不输出分布。港股宽度、资金流、仓位和一致预期接口仍缺失 |

五类及每只自选股经营/风险均有change_checks；已检索、搜索失败、保留候选、已保存正文和结论分别记录。未查不能填“未发现事件”；缺必要证据保留missing，不为每天五条新闻硬凑事实。检查表填满也不是覆盖充分或事实正确的证明。

报告和口播中的超预期、低于预期、未定价、空头回补、资金流入驱动等肯定措辞，需事前基线与实际值的逐字证据、带时区时点和同指标/单位/期间。程序先检查引用/时间次序/声明口径，审稿仍须对照原文检验语义、时点、可比性与判断强度。文字启发式不能识别所有同义写法，不是事实验证器或投资结论认证。

## 用量及输入

正常4次模型，最多一次条件补查评估不变，不添加新的模型循环，不放宽已接受的金额、搜索或公开请求上限。

4只A股：4个公告目录请求，初始付费搜索8→16项（两个公司问题各4项）；另两个宏观/行业槽只调整问题，不新增。每次先向搜索服务请求5条结果，约80条搜索候选的上限与旧8×10相当；不是从已有目录中悄悄删掉一半。每个事件仍优先读一篇代表稿，必要时最多一次替代，补搜不批量读全文。检索更广但每个查询深度更浅，漏收风险需用真实回执评估；检索不保证找全。

初始付费搜索整批与剩余模型阶段一起预检；只有原预算能容纳才开始该批，后续新正文增大输入仍可能停下。搜索费用会增加8×配置的单次搜索价，金额上限不变，不宣称更广的覆盖免费。免费的本地预检不联网也不扣费。

行情与宽度不调用模型或Tavily，公开请求共用原账本。指数一批，宽度最多128次请求、90秒预算（单次连接仍受剩余期限约束），至少留下24次网页请求；冷目录预计无法完成时先计数、再拒绝整批，不花请求下载注定不完整的全集。每次请求先持久记账；目录首尾计数分别取样防止变化，失败不自动重试。缓存保留原观察日；逐股报价晚于原截止不接纳。美股接口未声明时区，原始时钟保留，不宣称跨市场同步或最近完成时段已核实。

为避免重复输入，行情数值以一个明确派生数据来源保存，输入摘要只放来源ID和缺口；不是媒体原文，不当作最新收盘或政策原披露。该来源和原始响应跟本期回执保存。历史续跑拒绝用实时行情回填过去。
