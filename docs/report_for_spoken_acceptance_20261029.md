# 2026-10-29 A/H短线早报

**先说结论：** 隔夜最重要的变化是美联储10月28日维持利率不变，但声明把经济评价上调为"强劲"，并有两名票委主张加息。这对A股和港股的风险偏好偏压制。截至10月28日，恒生科技和科创50已经分别反弹约1.40%、2.45%，但中期仍偏弱。我倾向于先检验这轮修复能否延续，不把一天上涨当作趋势反转。以上是推断，不是已发生的事实。

## 一、美联储：利率不变，但偏鹰

**事实：** 联储将联邦基金利率目标区间维持在3.75%至4.00%，10比2的投票里，库克与哈马克主张加息25个基点，声明将经济评价由"稳步"上调至"强劲" [N:media-ff08212908a4ef6435c567e5][N:overseas-a0c3e1be77e8b5a27f797ac2]。主席沃什称不预判12月决策，并表示利率对AI投资同样有传导效应，他对"AI回报高所以不受利率影响"的说法持怀疑态度 [N:media-4c1a6c01d2672d5d10bad344]。加拿大央行同日加息25个基点至2.5%，理由是能源价格高企带来通胀风险 [N:media-22dea1a7e96dbc70cee043d7]。

**传导（推断）：** 海外利率预期偏高，会压制高估值成长板块的估值，也会抑制外资风险偏好。港股科技与A股科创、创业板可作为这种估值压力的观察对象；没有比较各板块利率敏感度，不能断言它们最敏感。

**证据与现状：** 行情截至10月28日（A股、港股各自收盘），恒生科技收3853.72点，近20日下跌10.30%，RSI14为33.54。科创50近20日下跌22.95%，创业板指下跌22.51%。沪深300的RSI14为30.20，已到传统超卖线附近。恒指当日收涨0.23% [N:direct-83c2682b1865034d1692b88b]。

**反证：** 这些下跌发生在联储决议之前，所以不能说联储造成了下跌。超卖也只是价格描述，不等于反弹确认。另有Pimco减持AI相关债券的报道（彭博援引知情人士）[N:media-b4afd4dd5dded7eac0f39dc0]，提示AI融资链有压力，但这只是风险线索，不是A/H的直接事实。

**今天怎么看：** 应检查10月28日已经发生的反弹能否延续，而不是“收复昨日跌幅”。若随后回吐修复成果，短线反弹持续性的依据减弱；若后续已完成日线的高低点逐步抬高，则需要重估下降结构。当前没有可用的指数成交量和市场宽度，不把“同步放量”写成已经可核验的判据。

## 二、自选股：宁德时代的锂价变量

宁德时代截至10月28日收229.14元，近20日下跌24.78%，RSI14为24.64，属传统技术性超卖，处在下降结构里。近5期自身收益约+0.54%，前5期约-18.64%；对应相对沪深300的收益差分别约+1.23、-16.13个百分点。自身表现和相对表现都改善，但这仍不证明有独立公司催化。

**新增事实：** 内盘碳酸锂主连28日收盘跌4.64% [N:direct-3af3512b7bcb07c949094932]。锂盐企业三季度单季净利环比多数下滑，分析师称10月以来碳酸锂加速下跌的原因是"旺季不旺"和供给宽松 [N:direct-476b56ccff4073de72311223]。另有二手综述称锂电板块行业营收整体上行，宁德时代利润增速低于营收增速 [N:9f0c5d394f627fcf205cd289]。

**判断：** 材料没有宁德时代的公司专属公告，也没有它的原料成本数据。锂价下跌对电池厂的成本是否有利，要看库存与定价机制，这些都未核实。短线上，它仍属于超卖后的弱势结构。原料价格下降可能减轻成本，也可能反映需求转弱，不能把锂价止跌当成电池股改善的必要条件。未来数日先观察它相对沪深300的改善是否延续；若转弱，应收回“相对改善可能延续”的假设，而不是否认过去五期已经发生的表现。
